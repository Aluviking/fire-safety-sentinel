# SISO — Sitio Web

Sitio web corporativo de SISO (Asesoría y Gestión Empresarial S.A.S.), desarrollado por [Rubik Control Digital](https://www.rubikcontroldigital.com/).

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Desarrollo local

```sh
# 1. Clonar el repositorio
git clone <URL_DEL_REPO>

# 2. Entrar a la carpeta del proyecto
cd fire-safety-sentinel

# 3. Instalar dependencias
npm i

# 4. Levantar el servidor de desarrollo
npm run dev
```

## Build de producción

```sh
npm run build
```

Los archivos listos para publicar quedan en la carpeta `dist/`.
